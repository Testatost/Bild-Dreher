# Bild-Dreher
ein einfaches Programm zum Drehen von Bildern

![alt text](https://github.com/Testatost/Bild-Dreher/blob/main/Bild-Dreher.png?raw=true)

## ✨ Funktionen

- 🔁 **Drehen** um ±90° oder 180°
- ↔️ **Horizontal spiegeln**
- 🧩 **Massenaktionen** für alle Bilder
- 📸 **Vorschau** des aktuellen Bildes mit allen geplanten Bearbeitungen
- 💾 **Speichern im Originalordner** oder optional als Kopie in Zielverzeichnis
- 📂 **Drag & Drop** von Dateien oder Ordnern
- ⌨️ **Tastatursteuerung**:
  - ↑ / ↓ : zwischen Bildern navigieren  
  - **Entf** : markierte Zeilen löschen  
  - **Strg+Z** : „Originalzustand“ wiederherstellen  
  - **Enter** : Speichervorgang starten
